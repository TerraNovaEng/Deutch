# Deutch
Inspired by general community integration workbooks or standard beginner curricula (A1)

Goal:

└── /Deutch-app (GitHub Repository)
    ├── index.html            (Main Single Page App & Tree UI Canvas)
    ├── /css
    │   └── style.css         (Layout, tree nodes, HTML card styling)
    ├── /js
    │   ├── app.js            (State manager, tree renderer, click events)
    │   └── data.js           (JSON structure: Levels -> Modules -> Dialogues)
    ├── /assets
    │   ├── /images           (Sketches, character avatars)
    │   └── /audio            (Optional voice clips for pronunciation)
    └── manifest.json         (Enables "Add to Home Screen" download capability)
